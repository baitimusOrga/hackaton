# Badge
Uppercase `caption` label naming a listing's sale mode or a status.

**Provide:** `label`, optionally `variant`.

**Use**
- Default outlined: "Festpreis", "Preisvorschlag", condition ("Wie neu").
- `inverse`: "Auktion" — the heavy mode gets the heavy badge.
- `green`: "Grüne Wahl" outlined in `green-text` on `bg-000`, only on listings that meet the criteria.
- `danger`: "Überboten", "Entfernt" — always with the word, never a colour alone.

**Don't**
- Badges never sit on top of photos; they go in the row under the image.
- Maximum two badges per card plus the timer.
